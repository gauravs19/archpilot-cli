# Contributing to Archpilot CLI

First off, thank you for considering contributing to Archpilot CLI! It's people like you that make Archpilot such a great tool.

## 1. Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check our [Issues](https://github.com/gauravs19/archpilot-cli/issues) page to see if someone else in the community has already created a ticket. If not, go ahead and [make one](https://github.com/gauravs19/archpilot-cli/issues/new)!

## 2. Developing locally

1. Fork the repo
2. Clone your fork: `git clone https://github.com/YOUR-USERNAME/archpilot-cli.git`
3. Install dependencies: `npm install`
4. Link locally: `npm link`
5. Test your changes by running `archpilot` in a dummy directory.

## 3. Pull Request Process

1. Create a branch for your feature: `git checkout -b feature/your-feature-name`
2. Make sure your code is clean and tested.
3. Commit your changes.
4. Push to the branch: `git push origin feature/your-feature-name`
5. Submit a pull request.
